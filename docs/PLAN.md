# Tab Tape 开发规划

日期：2026-10-08。目标用户：Mac + Chrome + Ableton 的个人音乐采样用途。

## v0.1：可直接加载的本机录音扩展

验收标准：

1. 用户主动在目标标签页点击扩展开始录音，只捕获该标签页音频。
2. 录制时能正常收听，关闭弹窗不影响捕获；随时可重新打开停止。
3. 显示真实采样帧对应的时长、实际采样率和左右声道峰值。
4. 直接记录 Float32 PCM；32-bit Float WAV 样本保持一致，24-bit PCM 导出正确量化。
5. 音频块及帧数原子提交，停止时清空尾部；写入失败停止采集并保留已保存片段。
6. 录音库支持重新下载和确认删除，意外中断后能导出已写入的数据。
7. 无生产依赖、无远程服务，通过 Chrome「加载已解压的扩展程序」安装。

架构：

```text
中文弹窗／录音库 ←消息→ Service Worker（用户授权、下载与角标）
                              ↕消息
                        Offscreen 页面
                         ↙          ↘
              标签页音频流          IndexedDB（元数据 + PCM 块）
                  ↓                       ↓
             AudioContext              WAV 导出
              ↙       ↘
        扬声器监听   AudioWorklet → 交错 Float32 PCM
```

实现顺序：核心接口与数据契约 → 音频模块和 UI 并行 → 后台控制整合 → WAV/存储/浏览器验证 → 安装说明与 ZIP。
